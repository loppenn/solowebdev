# Сайт веб-разработчика

Статический сайт (`index.html`) + serverless-функция `api/submit.js` (Vercel) + отправка писем через Resend.

## Запуск локально
1. `cp .env.example .env` и заполните значения.
2. `npx vercel dev` — откроется сайт вместе с `/api/submit`. (Просто открыть index.html недостаточно: форме нужен сервер.)

## Что настроить вам
- **RESEND_API_KEY** — создайте ключ на resend.com → API Keys.
- **ORDER_NOTIFICATION_EMAIL** — ваш email, куда приходят заявки.
- **ORDER_FROM_EMAIL** — адрес отправителя. Для реальной работы нужен домен, подтверждённый в Resend (Domains). Тестовый `onboarding@resend.dev` отправляет только на email владельца аккаунта Resend.
- **ALLOWED_ORIGIN** — адрес сайта после деплоя (ограничивает запросы с чужих сайтов).

## Деплой
`npx vercel`, затем добавьте те же переменные в Project → Settings → Environment Variables и сделайте redeploy.

## Замена демо-проектов
Массив `PROJECTS` в конце `index.html`.

## Ограничения
Защита от повторов и лимит запросов хранятся в памяти функции и сбрасываются при холодном старте; для строгого лимита подключите Upstash/Vercel KV. Отправка писем не проверена без ваших ключей.
